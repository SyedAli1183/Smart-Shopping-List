# Smart Shopping List App

A simple and useful shopping list web app built with Streamlit.

Add items, set quantities and prices, mark them as bought, and automatically calculate your total cost.

---

## Features

- Add items with category, quantity, and price
- Mark items as bought
- Automatic total cost calculation
- Delete individual items
- Summary by category
- Data is saved automatically

---
